# T-BCM — расшифровка аудиозаписей в Word

Программа превращает запись разговора в текст, разделяет реплики участников
и добавляет время каждой реплики. Готовый документ сохраняется в формате Word
в папку `WORD_FILE` рядом с программой.

Подходит для Windows 10 и 11, 64-разрядная версия. Для установки нужен интернет
и несколько гигабайт свободного места. Желательно иметь 16 ГБ оперативной памяти.
Python заранее устанавливать не нужно — программа подготовит его сама.
Word нужен только для просмотра документа; вместо него можно использовать LibreOffice.

## Как получить программу

### Вариант 1 — скачать архив с GitHub

Регистрация на GitHub для скачивания публичного проекта не нужна.

1. Откройте [страницу программы](https://github.com/Andrew-Rodionov/Transcriber).
2. Нажмите зелёную кнопку **Code**, затем **Download ZIP**.
3. Нажмите на скачанный архив правой кнопкой мыши и выберите **Извлечь всё**.
4. Переместите распакованную папку в удобное постоянное место, например
   `C:\Transcriber`. Не запускайте программу прямо из архива.
5. Выполните установку по инструкции ниже.

Если вы пользуетесь Git, вместо скачивания архива можно выполнить:

```powershell
git clone https://github.com/Andrew-Rodionov/Transcriber.git
```

После этого откройте созданную папку `Transcriber` и выполните установку.

### Вариант 2 — перенести с другого компьютера на флешке

Да, файлы программы можно перенести на флешке. На новом компьютере всё равно
нужно один раз запустить установку с интернетом. Простое копирование уже
установленной папки не заменяет установку: служебные файлы могут содержать
пути к старому компьютеру.

1. На компьютере с программой откройте её папку.
2. Создайте на флешке папку `Transcriber`.
3. Скопируйте в неё следующие файлы и папку целиком:

   ```text
   desktop\
   Start.bat
   Start-desktop.bat
   bootstrap.ps1
   create-shortcut.ps1
   desktop_main.py
   requirements.txt
   README.md
   ```

4. Если нужны готовые расшифровки, дополнительно скопируйте папку `WORD_FILE`.
5. На новом компьютере скопируйте папку с флешки в постоянное место на диске.
6. Выполните установку, описанную ниже, и настройте свой токен доступа.

Папки `.venv-desktop`, `.desktop-data`, `.git` и `del` переносить для установки
не нужно. Чужой файл `.env` с личным токеном также копировать не следует.
Библиотеки и модели на новом компьютере будут скачаны заново.

## Первая установка

1. Откройте папку программы и дважды нажмите **Start.bat**.
2. Дождитесь завершения установки. Программа скачает Python и необходимые
   библиотеки. Это может занять время; окно установки не закрывайте.
3. После установки на рабочем столе появится ярлык **T-BCM Desktop** со значком
   телефона и откроется программа.
4. Перед первой обработкой настройте токен доступа, как описано ниже.

При запуске батника чёрное окно может кратко появиться и закрыться — это нормально.
При запуске через ярлык чёрное окно не открывается.

Программа устанавливается в свою папку. Не удаляйте и не переименовывайте её
после установки: ярлык ссылается на файлы внутри. Если папку переместили,
повторите **Start.bat** на новом месте, чтобы обновить ярлык и проверить установку.
Если после перемещения приложение не открывается, установите его заново из чистых
файлов по варианту переноса выше; документы из `WORD_FILE` можно сохранить отдельно.

## Как настроить доступ к моделям

Для того, чтобы получить доступ к моделям необходим уникальный токен ключ. Он находится
в файле .env вместе с другими данными. Шаблон файла выглядит так:

**HF_TOKEN=*ВАШ ТОКЕН***

**DEFAULT_MODEL_SIZE=small**

**DEFAULT_COMPUTE_TYPE=int8**

**DEFAULT_DEVICE=cpu**


## Как получить расшифровку

1. Откройте **T-BCM Desktop** на рабочем столе или **Start-desktop.bat** в папке программы.
2. Оставьте модель **small** — она выбрана по умолчанию. Более крупные модели
   можно выбрать вручную; они требуют больше памяти и времени.
3. Выберите язык: **ru** — русский, **en** — английский, **auto** — определить автоматически.
4. Нажмите **Добавить файлы** и выберите одну или несколько записей.
5. Нажмите **Запустить очередь**. До нажатия этой кнопки записи не обрабатываются.
6. Дождитесь состояния **Готово** напротив нужного файла.
7. Нажмите **Папка результатов**. Откроется вся папка `WORD_FILE`, включая документы
   от предыдущих запусков. Откройте нужный документ двойным щелчком.

Например, из записи `совещание.wav` получится файл:

```text
расшифровка_совещание_2026-11-23_14-30-25_123456.docx
```

В имени указаны дата и время сохранения. Повторная расшифровка создаёт новый документ.
В документе участники обозначены условно: «Участник 1», «Участник 2» и так далее.
Время каждой реплики отсчитывается от начала записи. Автоматический текст и
разделение голосов нужно проверить перед использованием.

## Что важно во время работы

- При первой обработке программа дополнительно скачивает модели. Надпись
  **Идёт подготовка модели…** означает, что работа продолжается. Это может занять время.
- Интернет нужен для установки и загрузки моделей. Новый язык или новая модель
  могут потребовать дополнительной загрузки.
- Сама расшифровка выполняется на вашем компьютере. Несколько файлов обрабатываются
  по очереди, а модели повторно используются между файлами.
- Если добавить файлы во время работы, для них тоже нужно нажать **Запустить очередь**.
- Ошибка одного файла не останавливает обработку остальных. Дважды нажмите на строку
  с ошибкой, чтобы прочитать подробности.
- **Остановить очередь** прерывает обработку отправленных заданий. Для повторной
  обработки отменённые записи нужно добавить заново.
- Для изменения модели или языка сначала нажмите **Остановить очередь**.
- Закрытие окна полностью завершает обработку. Готовые документы остаются в `WORD_FILE`,
  а незавершённые задания после нового запуска нужно добавить заново.

## Чем отличаются файлы запуска

| Файл | Для чего нужен |
|---|---|
| `Start.bat` | Устанавливает или обновляет необходимые компоненты, создаёт ярлык и открывает программу. |
| `Start-desktop.bat` | Открывает уже установленную программу. Установку библиотек не запускает. |
| Ярлык `T-BCM Desktop` | Открывает ту же программу без консоли. По назначению заменяет `Start-desktop.bat`. |
| `bootstrap.ps1` | Выполняет установку. Его автоматически вызывает `Start.bat`. |
| `create-shortcut.ps1` | Создаёт ярлык. Его автоматически вызывает установщик. |

Файлы `.ps1` нужно оставить в папке программы. Самостоятельно запускать их не требуется.
При первом распознавании загрузка моделей возможна даже при запуске через ярлык:
это подготовка распознавания, а не повторная установка библиотек.

## Если что-то не работает

**Программа не установлена или нет ярлыка.** Запустите **Start.bat** из папки программы.

**Установка прервалась.** Проверьте интернет и свободное место, затем повторите
**Start.bat**. Если ошибка повторяется, передайте специалисту файл
`.desktop-data\install.log`.

**Не указан токен или нет доступа к модели.** Проверьте файл `.env` и убедитесь,
что условия модели приняты в том же аккаунте, где создан токен. Перезапустите программу.

**Ошибка сертификата, `CERTIFICATE_VERIFY_FAILED`.** Проблема связана с защищённым
соединением. Если компьютер рабочий, передайте сообщение системному администратору:
может потребоваться настройка сертификата корпоративного прокси или антивируса.
Смена токена не решает эту ошибку.

**Ошибка при обработке записи.** Подробности находятся в `.desktop-data\worker.log`.
Если окно приложения вообще не открылось, проверьте `.desktop-data\desktop.log`.

**Windows запрещает запуск скрипта.** На рабочем компьютере обратитесь к системному
администратору. Организация может ограничивать запуск батников и PowerShell.

## Как обновить программу

1. Закройте приложение.
2. Скачайте свежий архив с GitHub и распакуйте его отдельно.
3. Скопируйте новые файлы программы в существующую папку с заменой одноимённых.
   Сохраните свой `.env`, папку `WORD_FILE` и служебные папки `.desktop-data` и `.venv-desktop`.
4. Запустите **Start.bat**. Он установит изменившиеся зависимости и обновит ярлык.

Если пользуетесь Git, получите обновления через него, затем также запустите **Start.bat**.
Сам установщик не скачивает новую версию исходного кода.

Папка `del`, если она осталась в вашей копии, содержит старые неиспользуемые файлы.
Для работы программы она не нужна.
