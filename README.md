# T-BCM

Десктопная расшифровка аудио и видео на Windows 10/11 x64. Записи обрабатываются
локально через WhisperX с обязательным разделением говорящих. Результат — `.docx`
с участниками и временем начала/конца каждой реплики. Microsoft Word для создания
файлов не требуется; открыть их можно в Word или LibreOffice.
Для чтения аудио используется встроенный FFmpeg; отдельно устанавливать его не нужно.

## Установка и ярлык на рабочем столе

1. Скачайте репозиторий через **Code → Download ZIP**, распакуйте в доступную для
   записи папку. Не запускайте из архива.
2. Дважды нажмите **Start.bat** — это установка и первый запуск. Windows может
   кратко показать окно батника, затем установка продолжится в отдельном окне.
3. При первом запуске появится окно установки: загрузятся локальные uv, Python 3.12
   и библиотеки. Установка занимает время и требует нескольких гигабайт свободного
   места и интернета. Права администратора и ручная установка Python не нужны.
   После успешной установки создаётся ярлык **T-BCM Desktop** на рабочем столе
   и открывается приложение. Дальше запускайте его через этот ярлык: он скрыто
   вызывает второй батник **Start-desktop.bat**, без установки и проверки обновлений.
4. Примите условия
   [модели pyannote](https://huggingface.co/pyannote/speaker-diarization-community-1)
   и создайте [Read token](https://huggingface.co/settings/tokens). В файле `.env`
   в папке программы задайте `HF_TOKEN=hf_ваш_токен`, затем перезапустите приложение.
   Это обязательный шаг владельца аккаунта, автоматизировать принятие условий нельзя.
   Поля токена в окне приложения нет.
5. Выберите модель и язык. Нажмите **Добавить файлы**, выберите записи, затем
   **Запустить очередь**. Добавление само по себе не начинает обработку.
   Если добавите файлы во время обработки, они тоже будут ждать отдельного
   нажатия **Запустить очередь**.

Документы всегда сохраняются в папку `WORD_FILE` рядом с программой.
Имя файла: `расшифровка_название-аудио_2026-11-23_14-30-25_123456.docx`.
Суффикс содержит дату, время сохранения и микросекунды, чтобы повторные обработки
не перезаписывали результат. **Папка результатов** открывает всю папку в Проводнике
и показывает все сохранённые в ней файлы, включая результаты предыдущих запусков.

Два батника выполняют разные задачи: **Start.bat** устанавливает или обновляет
окружение и создаёт ярлык, **Start-desktop.bat** запускает готовый десктоп.
`Start.vbs` и `Launch-desktop.vbs` — вспомогательные файлы для скрытия консоли.
Ярлык использует второй из них, чтобы окно второго батника тоже не появлялось.
Папка проекта должна оставаться на месте: это локальная установка в распакованную
папку. После её перемещения повторите **Start.bat**, чтобы пересоздать ярлык.

Рекомендуется 16 ГБ RAM и более; потребление зависит от модели и длины записи.
По умолчанию выбрана модель `small`. Поставляемая конфигурация работает на CPU;
ускорение NVIDIA в установщике пока не настроено. Длинные записи могут обрабатываться
медленно и требуют дополнительной памяти для декодированного аудио.

Первое распознавание скачает модели. Дальше они остаются на диске, а в пределах
одной очереди — ещё и в памяти. Первая обработка нового языка может скачать
дополнительную модель выравнивания. Полностью автономная установка без интернета
в эту версию не входит.

## Очередь и завершение

- Один фоновый процесс выполняет задачи последовательно (FIFO). Ошибка отдельной
  записи отображается в её строке; следующая запись продолжает обрабатываться.
- Модели распознавания и диаризации загружаются один раз на процесс. В памяти
  хранится выравниватель текущего языка; при смене языка он заменяется.
- Настройки фиксируются на время жизни процесса. **Остановить очередь** прерывает
  текущую задачу, отменяет ожидающие и освобождает модели. После этого можно
  изменить настройки и добавить файлы заново. Повтора ошибок автоматически нет.
- Закрытие окна завершает обработчик и его дочерние процессы через Windows Job
  Object. Незавершённые задания не восстанавливаются после повторного запуска.
- Приложение не занимает сетевой порт.
- Выходной формат десктопа — только Word. JSON и режима без диаризации в нём нет.
  Временные метки отсчитываются от начала записи; участники имеют условные имена.
  При смене говорящего внутри сегмента реплики формируются по меткам слов.
- Каждый результат получает уникальное имя; повторная обработка не перезаписывает
  предыдущий файл. Документ публикуется только после полного сохранения.

## Файлы и обновления

- `WORD_FILE/` — все сохранённые Word-файлы.
- `.desktop-data/models/` — скачанные модели.
- `.desktop-data/install.log` — журнал установки.
- `.desktop-data/worker.log` — журнал обработки.
- `.venv-desktop/` — отдельное окружение десктопа.
- `requirements.txt` — все зависимости с фиксированными версиями для Windows x64 / CPU.

При обновлении исходников сохраните эти папки и `.env`, затем снова запустите
**Start.bat**. Если `requirements.txt` изменился, установщик обновит библиотеки и пересоздаст
ярлык. Обычный запуск с рабочего стола этого не делает. Установщик не выполняет
`git pull`: обновление кода остаётся явным действием пользователя. Для переноса
на другой компьютер скачайте чистые исходники; окружение Python не переносимо.

Если установка оборвалась, повторите **Start.bat**. Если повреждено окружение Python,
переименуйте `.venv-desktop` и `.desktop-data/requirements.sha256`, затем повторите
запуск. Окно ошибки укажет журнал. Windows Script Host должен быть разрешён
политикой компьютера. В корпоративной среде его может блокировать администратор.

При ошибке `CERTIFICATE_VERIFY_FAILED` обновите код и запустите **Start.bat**,
затем повторите обработку. Десктоп использует доверенные сертификаты Windows
через truststore, сохраняя проверку HTTPS. Если корпоративный прокси или антивирус
подменяет сертификаты, его корневой сертификат должен быть установлен в доверенном
хранилище Windows администратором. Изменение Hugging Face token эту ошибку не исправляет.

Все библиотеки устанавливаются из одного `requirements.txt`. При ручной установке
в подготовленное окружение используйте:

```powershell
.desktop-data\uv.exe pip install --python .venv-desktop\Scripts\python.exe --index-strategy unsafe-best-match -r requirements.txt
```

Папка `del/` содержит выведенные из использования файлы и прежние примеры записей.
Она не участвует в запуске и исключена из Git; её можно перенести за пределы проекта.

## Проверки разработки

```powershell
python -m unittest discover -s tests -v
python -m compileall -q desktop desktop_main.py
```

Тесты проверяют разделение реплик, сохранение слов без выравнивания, повторное
использование моделей и продолжение очереди после ошибки. Проверки Word и окна
требуют `python-docx` и доступного Tk; запуск реальных моделей требует полной установки.
